# BenchCraft Lead CRM Demo

This folder contains a frontend-only demo of the CRM for Vercel or other static hosting.

## What it uses

- Mock course, lead, and sales data
- Fake "scouting" that generates believable local prospects
- `localStorage` so demo changes persist in the browser
- No Python backend, CSV files, or API keys

## Local run

```bash
npm install
npm run dev
```

## Deploy

Deploy this `demo/` folder as its own Vite app.
